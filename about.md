# Buffer Frame

Corrige tus clicks tempranos. Si das un click unos ticks antes de un pincho y vas a morir, el mod prueba el mismo click un poco más tarde y se queda con el primer retraso con el que sobrevives.

## Cómo funciona

1. Cuando das un click, el mod guarda una foto del juego.
2. Si mueres poco después, cancela la muerte y vuelve a esa foto.
3. Repite el intento con el click retrasado 1, 2, 3... ticks (hasta el máximo de los ajustes, por defecto 16).
4. Se queda con el primer retraso con el que sobrevives. Si ninguno funciona, mueres normal.

## Ajustes

- **Retraso máximo (ticks):** hasta cuánto puede retrasar un click.
- **Ventana de revisión (ticks):** cuánto tiempo después del click vigila si mueres.
- **Mostrar aviso en pantalla:** etiqueta pequeña mientras el mod está activo.

## Importante

<cr>Esto es un cheat de prueba.</c> No lo uses para rankeds, listas ni verificaciones. Mientras está activo, los niveles se juegan en modo prueba y no se guarda progreso.

## Limitaciones

- Si el retraso que te salva está lejos, verás pequeños saltos hacia atrás mientras prueba cada retraso.
- Los clicks que des mientras el mod repite un intento no se vuelven a reproducir si hay otro reintento.
- Versión inicial: puede fallar en niveles con muchos triggers o objetos en movimiento.
